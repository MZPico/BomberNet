# BomberNet on the Commodore 64

**Runs on:** any Commodore 64 or 128 in C64 mode, PAL or NTSC.

**Files:** `bombernet-0.3.0-c64.d64`, a disk image with the program
`BOMBERNET` on it, and `bombernet-0.3.0-c64.prg`, the program by itself.

## Loading

- From the disk image (a 1541, an SD2IEC, a 1541 Ultimate, a Pi1541):
  `LOAD"BOMBERNET",8,1` then `RUN`.
- The `.prg` loads the same way from any device that serves `.prg` files.

## Network play

Two devices work; the game finds whichever answers at start.

- **WiC64** on the user port: joined to your Wi-Fi with its own setup (its
  launcher or portal), as its manual describes. The game then uses the
  WiC64's TCP commands.
- **Ultimate 64, or a C64 with an Ultimate-II+:** the Ultimate's own network,
  through its Command Interface. In the Ultimate's menu, enable the command
  interface (under its cartridge or software settings) and have the
  Ultimate on your network; the game then opens its connections through it.

Without either, the title screen has no NETWORK row.

For a relay of your own, rewrite the `.d64` or the `.prg` file's relay
address with `tools/set_relay.py` from the sources (see the
[setup page](README.md#the-relay)).

## Keys

| | |
|---|---|
| Player 1 | cursor keys (CRSR with and without SHIFT), SPACE fires (RETURN when a second keyboard player is set) |
| Player 2 on the keyboard | W A S D, E fires |
| Joysticks | ports 1 and 2 |
| Leave a match, cancel a room code | RUN/STOP |

## In an emulator

VICE 3.9's x64sc emulates the WiC64 (`-userportdevice 23`, or Settings,
Peripheral devices, Userport) and plays through the relay. Other
emulators, and VICE without it, play locally.
