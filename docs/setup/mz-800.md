# BomberNet on the Sharp MZ-800

**Runs on:** a Sharp MZ-800; the game is an MZ-700 program and runs in the
MZ-800's MZ-700 mode. An MZ-700 plays it too, locally: no network device for
it is known to work.

**File:** `bombernet-0.3.0-mz800.mzf`, also on
[mzpico.com](https://mzpico.com/titles/bombernet/) as `bombernet.mzf`.

## Loading

- **MZPico:** the game is in the catalog's Featured folder, and under
  `cloud:/` when the card is online; or copy the `.mzf` to the card's SD.
  Load it as any other title.
- **Unicard, SD2MZ, Pro-700 and the like:** copy the `.mzf` and load it as
  usual.
- **Tape:** the `.mzf` is a tape image; mzpico.com's title page plays it as
  audio ("Tape audio") for a real cassette or a cable.

## Network play

- **MZPico** built on a Raspberry Pi Pico W, with Wi-Fi enabled in its
  configuration (`mzpico.ini`): nothing else to set. The card joins your
  Wi-Fi as it always does, and the game finds the card's network at start. For a relay of your own, `mzpico.ini`,
  `[cloud]`: `net_relay = <address>`, `net_port = 8765`.
- **Unicard** with the NET firmware: it talks to the relay over plain TCP
  (JSON lines), which the public relay does not accept, so it needs a relay
  of your own on the home network (see the [setup page](README.md#the-relay)).
  In `/unicard/network.cfg`: `NETRELAYADDR` is that PC's address,
  `NETRELAYPORT` 8766.

Without either, the title screen has no NETWORK row.

## Keys

| | |
|---|---|
| Player 1 | cursor keys, SPACE fires (CR when a second keyboard player is set) |
| Player 2 on the keyboard | W A S D, E fires |
| Joysticks | the MZ-800's joystick ports, or an MZ-1X03; JOYSTICK on the title screen picks the kind |
| Leave a match, cancel a room code | BREAK |

## In an emulator

mz800emu plays it locally. The [MZPico fork of mz800emu](https://github.com/MZPico/mz800emu)
emulates the MZPico card with its network and plays through the relay.
